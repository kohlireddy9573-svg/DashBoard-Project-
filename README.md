# DashBoard Project

A responsive dashboard landing page built with HTML and CSS. The project includes a dark left navigation panel, summary cards, user activity data, schedule blocks, and a contact form with embedded map.

## Project Structure

```text
Dash Board Project/
├── README.md
├── multimedia/
│   ├── index.html
│   ├── style.css
│   ├── BarGraph.png
│   ├── man.jpg
│   └── ShortBaby-Mg2w.ttf
└── ...
```

## Features

- Sidebar navigation with icons and sections
- Dashboard overview area with activity chart image
- Revenue, transactions, likes, and user summary cards
- User interaction table
- Schedule section with upcoming items
- Contact section with feedback form and map embed
- Mobile-friendly responsive layout styling

## Run Locally

1. Open the project folder.
2. Open `multimedia/index.html` in any modern browser.
3. Or run a simple local server:

```bash
cd "c:\Users\ACER\Documents\Dash Board Project"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/multimedia/
```
